Question: In this lesson, you created a middleware function called asyncWrapper. Why?
Answer: I created the middleware function asyncWrapper to wrap my controllers, and reduce repetition in my code; especially surrounding error handling for certain asynchornous operations; which was previously being done using the try catch block. That reduces the need for copying and pasting code. This can also be done with certain npm packages that reduce this set-up for us, but coding it in this manner gives us a general idea of what one these packages would be doing, and how they would function.
